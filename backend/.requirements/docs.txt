# Isolated documentation environment (#1597, epic #1589).
#
# Building the portal needs **only** this file: no backend dependencies, no
# Django, no GDAL, no database. `conf.py` reads the release string from the root
# VERSION file and `docs/source/_ext/mrmap_docs.py` decides what autodoc may
# claim when the application is not importable, so a contributor builds the docs
# with a venv plus this file and nothing else.
#
# Every line is pinned, transitive dependencies included, because the ADR-0001
# gate V-11 is "the committed pins build". The previous file pinned Sphinx 4.5.0
# beside sphinxcontrib-* 2.x - all five of which require Sphinx >= 5.0 - so the
# committed set aborted in about a second with a version error, and nothing
# noticed, because no job built the documentation on an ordinary change. Pinning
# the transitive closure is what makes that class of failure impossible rather
# than merely fixed once: an unpinned transitive upgrade cannot silently move
# under a pinned Sphinx again.
#
# To refresh: build in a clean venv, re-freeze only what `pip freeze` lists
# below, and run `python3 scripts/test_docs_build.py`.
